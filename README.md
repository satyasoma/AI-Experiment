# Satya Trainings

A polished, responsive coming-soon landing page for Satya Trainings, built with Next.js App Router and TypeScript.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

No backend, database, API routes, environment variables, or platform-specific runtime code are required.
